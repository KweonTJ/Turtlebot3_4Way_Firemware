# Turtlebot3_4Way_Firemware
# 개요

이 저장소는 **TurtleBot3 Burger 기반 4륜 구동 모바일 매니퓰레이터**를 만들기 위해 수정한 ROS 2 펌웨어를 관리한다.

기존 TurtleBot3 Burger는 2륜 차동 구동 구조라서 매니퓰레이터를 올리면 무게 중심, 구동 안정성, 적재 능력에서 한계가 생긴다.  
Waffle을 사용할 수 없는 환경에서도 Burger 기반 하드웨어를 확장해 **4륜 구동 베이스 + 매니퓰레이터** 구조로 운용하는 것이 이 프로젝트의 목적이다.

---
# 기존 플랫폼의 한계

## TurtleBot3 Burger

TurtleBot3 Burger는 작고 다루기 쉬운 플랫폼이지만, 모바일 매니퓰레이터 용도로 쓰기에는 한계가 있다.

- 기본 구조가 2륜 차동 구동이다.
- 매니퓰레이터 장착 시 무게 중심이 불안정해진다.
- 하중이 증가하면 주행 안정성이 떨어진다.
- 직진성과 회전 안정성이 외란에 민감하다.
- 적재 공간과 구동력이 부족하다.

## TurtleBot3 Waffle을 쓰기 어려운 경우

Waffle은 Burger보다 확장성이 좋지만, 항상 사용할 수 있는 것은 아니다.

- Waffle 플랫폼이 없는 경우
- 기존 Burger 하드웨어를 재활용해야 하는 경우
- 예산 제약이 있는 경우
- 소형 플랫폼 기반 4륜 구동 실험이 필요한 경우

그래서 이 프로젝트는 **Burger를 4륜 구동 구조로 개조하고, 매니퓰레이터까지 함께 운용할 수 있는 펌웨어**를 만드는 데 집중한다.

---
# 프로젝트 목표

- TurtleBot3 Burger 기반 4륜 구동 시스템 구현
- 매니퓰레이터 장착 시 주행 안정성 확보
- ROS 2 환경에서 모바일 베이스 제어
- 기존 TurtleBot3 펌웨어 구조 유지
- UROP 연구용 모바일 매니퓰레이터 플랫폼에 적용

---
## 주요 수정 내용

- 2륜 구동 구조를 4륜 구동 구조로 변경
- 4개의 Dynamixel 모터를 구동 모터로 사용
- 좌우 속도 명령을 앞/뒤 바퀴에 분배
- ROS 2 TurtleBot3 제어 구조와 호환
- 매니퓰레이터 장착을 고려해 모바일 베이스 구동부 확장
